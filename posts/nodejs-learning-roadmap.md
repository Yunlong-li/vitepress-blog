# Node.js 学习路线（有 JS 基础）

如果你已经有一定的 JavaScript 基础，学习 Node.js 的核心思路是：

- **先补运行时差异**（浏览器 JS vs Node.js）
- **再掌握后端开发主线**（HTTP、数据库、鉴权、日志）
- **最后用项目闭环**（开发、测试、部署、监控）

---

## 1. 先建立 Node.js 运行时认知

### 1.1 Node.js 和浏览器 JS 的区别

重点理解：

- 全局对象：`window` vs `globalThis`
- 模块系统：ESM / CommonJS
- Node API：`fs`、`path`、`process`、`Buffer`
- 事件循环在 Node 场景下的表现（`setImmediate`、`process.nextTick`）

### 1.2 必会内置模块

先把这几个用熟：

- `fs/promises`：文件读写
- `path`：路径拼接（跨平台）
- `url`：URL 处理
- `crypto`：摘要、加密、随机字符串
- `events`：事件驱动

建议做 2 个小练习：

1. 写一个脚本批量重命名文件。
2. 写一个读取 JSON 配置并生成 Markdown 的脚本。

---

## 2. 后端开发主线（推荐 Express 或 Fastify）

### 2.1 HTTP 基础

你要能说清楚并能落地：

- 请求方法、状态码、请求头
- 路由参数、查询参数、请求体
- 中间件执行顺序
- 错误处理机制

### 2.2 RESTful API 设计

建议你从以下规范开始：

- 资源化命名：`/users`、`/orders/:id`
- 分页、筛选、排序参数统一
- 返回结构统一：`{ code, message, data }`
- 错误码分层（业务错误 / 系统错误）

### 2.3 数据库入门

首选一套关系型数据库（如 MySQL + Prisma）：

- 表设计（用户表、文章表、评论表）
- 事务、索引、唯一约束
- 避免 N+1 查询

你也可以补一个 Redis：

- 登录态缓存
- 热点数据缓存
- 分布式锁（了解即可）

---

## 3. 工程能力：从“能写”到“可上线”

### 3.1 配置管理

- 环境变量分层：dev / test / prod
- 敏感信息不入库
- 配置校验（启动时失败优于运行时失败）

### 3.2 日志与监控

至少要有：

- 访问日志
- 错误日志（含堆栈、请求上下文）
- 慢请求统计

### 3.3 测试

建议顺序：

1. 先写核心工具函数单测。
2. 再写 API 集成测试（登录、鉴权、核心 CRUD）。
3. 覆盖异常流程（参数非法、权限不足、数据库异常）。

---

## 4. 建议实战项目（按难度递进）

### 项目 A：博客后端 API（入门）

功能：

- 用户登录注册
- 文章 CRUD
- 标签分类
- 分页查询

目标：熟悉完整后端开发流程。

### 项目 B：任务管理系统（进阶）

新增：

- RBAC 权限控制
- 操作审计日志
- 文件上传
- 缓存与限流

目标：提升工程化能力。

### 项目 C：微服务拆分（提升）

- 网关层
- 用户服务 / 内容服务拆分
- 消息队列（异步通知）

目标：建立系统设计视角。

---

## 5. 你可以这样安排 6 周学习

- 第 1 周：Node 运行时 + 核心内置模块
- 第 2 周：HTTP + 路由 + 中间件
- 第 3 周：数据库 + ORM
- 第 4 周：鉴权 + 日志 + 错误处理
- 第 5 周：测试 + 缓存 + 部署
- 第 6 周：项目打磨 + 简历沉淀
